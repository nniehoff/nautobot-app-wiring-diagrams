# Release Notes

All the published release notes can be found via the navigation menu. All patch releases are included in the same minor release (e.g. `v1.2`) document.

No version has been released yet. Unreleased changes are kept as [towncrier](https://towncrier.readthedocs.io/) fragments in `changes/`; `invoke generate-release-notes` writes them into a `version_X.Y.md` page here at release time (see the [Release Checklist](../../dev/release_checklist.md)).
