# Compatibility Matrix

The app declares `min_version = "3.2.0"` and supports every Nautobot 3.x release from there. CI tests it against Nautobot 3.2.0 and the latest stable release.

| Nautobot Wiring Diagrams Version | Nautobot First Support Version | Nautobot Last Support Version |
| ------------- | -------------------- | ------------- |
| 0.1.X         | 3.2.0                | 3.99.99       |
